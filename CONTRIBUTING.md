# Contributing

Thank you for helping improve the PyWaw community resources.

## Before opening a pull request

1. Open or review an issue describing the problem or proposed improvement.
2. Keep each pull request focused on one change.
3. Prefer clear, practical language that works for first-time speakers and Python learners.
4. Do not add private attendee information, personal contact details, or claims about community size without an authoritative public source.
5. Check that every relative Markdown link points to an existing file or directory.

## Validation

Run the repository's documentation link check locally:

```bash
python scripts/check_markdown_links.py
```

The same check runs automatically for pull requests and pushes to the `main` branch through GitHub Actions.

## Review expectations

A maintainer may request clarification or revisions before merging. Please explain the purpose of a change and include relevant sources when adding factual claims.

## Scope

This repository contains reusable community documentation. It is not an official event archive, membership database, or record of attendance.
